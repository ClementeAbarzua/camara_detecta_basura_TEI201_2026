# Datos de las pruebas

Datos exportados de la base de datos PostgreSQL (Aiven) durante las pruebas.

> [PENDIENTE: exportar las mediciones de las pruebas y guardarlas aquí, por ejemplo `mediciones_2026-11-23.csv`.]
> En el dashboard: **Acceso de administrador** → `/admin` → exportar en CSV.

| Archivo | Descripción |
|---|---|
| `mediciones_AAAA-MM-DD.csv` | Una fila por foto analizada: fecha y hora, probabilidad de cada clase, promedio, umbral y conclusión |
